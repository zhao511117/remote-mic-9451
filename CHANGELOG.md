# Changelog

## 0.1.0 — 2026-11-10

First public source release of the 18D1:9451 Windows adaptation: paired-cache BLE transport, clone-specific frame decoding/recovery and hold-cycle extension, Doubao shortcut integration, device-scoped navigation, optional pinned-build extra-key suppression, foreground/minimize application toggles, Startup helper and bounded process recovery.

Public packaging adds per-installation private configuration, paired-device selection, configurable application/audio paths, default-off experimental HID hooks, source tests, documentation and provenance notices. The existing single-machine deployment was not replaced by the public packaging. Broader hardware and platform compatibility remains unverified.
